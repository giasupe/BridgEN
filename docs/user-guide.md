# BridgEN ベータ版

英語のゲーム画面を読み取り、日本語訳を重ねて表示するWindowsアプリです。

## 初回起動

1. ZIPをフォルダへ展開し、`BridgEN.exe`を起動します。ZIP内から直接実行せず、DLLなども一緒に展開してください。.NETの追加インストールは不要です。
2. 「翻訳の接続設定」を開き、「中継サーバー（配布版）」を選びます。
3. 管理者から案内されたサーバーURLと、自分用の招待トークンを入力して保存します。GeminiのAPIキーは利用者側では不要です。
4. 対象ウィンドウを選び、「読む範囲を選択」を押します。選んだウィンドウが自動で前面に表示されるので、会話欄全体をドラッグします。最小化されている場合は元に戻します。右クリックで範囲選択をキャンセルできます。
5. 「操作モード」を選び、オートマチックなら「OCRを開始」、マニュアルなら「待機を開始」を押してゲームを前面にします。

## 操作モード

- **オートマチック（初期値）**：ゲームが前面にある間、会話文を自動で読み取り、安定した文章を翻訳します。
- **マニュアル**：ゲームが前面のときに設定した実行キーを押すと、その画面を1枚だけ読み取り、翻訳します。キーを押すまで画面取得もOCRも行わず、連続画像による安定待ちも行いません。

マニュアルの実行キーは初期値がF8です。キーの欄をクリックして好きなキーを押すと変更できます。Ctrl・Shift・Altなどとの組み合わせも設定できます。モードとキーは自動保存され、再起動後も引き継がれます。

文章が表示し終わってから押してください。長押しでは1回だけ実行し、OCR中の追加押下は予約しません。翻訳の受信中に押した場合は前の翻訳を取り消し、新しい画面を読み取ります。実行キーはゲームにも届きます。

マニュアルは`v0.1.0-beta.2`以降で利用できます。

## 接続とOCRの準備

Windowsの英語（米国）OCR言語機能が必要です。OCRが使えない旨が表示された場合は、Windowsの設定から英語（米国）の言語機能とOCRを追加してください。

「Geminiへ直接接続」を選ぶ場合、サーバーURLと招待トークンは不要です。環境変数`GEMINI_API_KEY`（または`GOOGLE_API_KEY`）に設定した自分のAPIキーを使います。接続方式を変えた後は「接続設定を保存」を押してください。

## 利用とデータ

- ゲームが前面にある間だけ読み取ります。
- 画像はPC内で処理し、採用した英文を中継サーバー経由でGoogleのGemini APIへ送ります。
- 中継サーバーは本文・画像・生の招待トークンを保存せず、利用上限のカウンターを保存します。Google側のデータの取扱いは利用中のGemini APIの条件に従います。
- 招待トークンはWindowsユーザーに紐付けて暗号化し、`%LOCALAPPDATA%\BridgEN\connection.json`に保存します。別のPCへこのファイルをコピーしても、そのまま使うことはできません。
- 操作モードと実行キーは`%LOCALAPPDATA%\BridgEN\ocr-settings.json`に保存します。接続設定や招待トークンの保存ファイルとは別です。
- ベータ版の初期上限は1人300回/日・20回/分、全体1,000回/日・60回/分です。日次上限は日本時間の午前9時にリセットされます。
- 上限はGeminiへの送信を試みた回数です。送信後のキャンセルやAPIエラーも数え、アプリが自動で繰り返し課金リクエストを再送することはありません。
- OCRの誤認識・翻訳の誤りが起きる場合があります。長い文章で送信上限が表示された場合は、読む範囲を小さくしてください。

## トラブル時

- 「招待トークンが無効」: 管理者から届いた値を再登録してください。
- 「サーバーの設定が未登録」: 管理者側のSecret設定が必要です。
- APIエラー後に再試行する場合は、OCRを停止して再開してください。
- OCR結果と処理時間を確認する場合はゲームからBridgENへ切り替えます。読み取りは停止し、直前の完成結果と計測値を確認できます。「処理時間」は初期状態では折りたたまれており、クリックすると計測値を表示します。

初期の配布物はコード署名を付けていません。Windowsの保護機能による確認が表示される場合があります。配布元とZIPのSHA-256を確認してください。
