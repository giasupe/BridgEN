## 更新内容

- 操作モードを「オートマチック」と「マニュアル」から選べるようにしました。初回はオートマチックです。
- マニュアルでは、設定したキーを押したときだけ画面を1枚取得し、OCRと翻訳を実行します。
- マニュアルの実行キーを変更できます。初期値はF8で、Ctrl・Shift・Altなどとの組み合わせにも対応します。
- 操作モードとキー設定を保存し、次回起動時に引き継ぎます。

## 起動方法

1. Assetsの `BridgEN-0.1.0-beta.2-win-x64.zip` をダウンロードし、すべて展開します。
2. 展開先の `BridgEN.exe` を起動します。.NETは同梱しています。
3. 翻訳の接続設定、対象ウィンドウ、読み取り範囲を設定します。
4. マニュアルを使う場合は「操作モード」を切り替え、「待機を開始」を押し、ゲームを前面にして実行キーを押してください。

Windows x64、英語（米国 / en-US）のWindows OCR言語機能、翻訳用のインターネット接続が必要です。中継サーバーの利用には、管理者から個別に受け取った招待トークンが必要です。

画面画像はPC内でOCR処理し、認識した英文をGoogleのGemini APIへ送って翻訳します。中継サーバーには利用上限があります。詳しくは同梱のREADMEをご覧ください。

ベータ版のため、ゲームのフォントや背景によって読み落としや誤訳が起きる場合があります。マニュアルでは文章が表示し終わってからキーを押してください。実行キーはゲームにも届きます。
