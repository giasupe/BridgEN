# BridgEN

**英語のゲームを、日本語訳を見ながら遊ぶためのWindowsアプリです。**

ゲームの会話欄を指定すると、画面の英語を読み取り、日本語訳をゲーム画面の上部に重ねて表示します。翻訳は受信した部分から順に表示されます。

## ダウンロード

**[GitHub Releasesから配布版をダウンロード](https://github.com/giasupe/BridgEN/releases)**

Releaseの **Assets** にある `BridgEN-バージョン-win-x64.zip` を選んでください。`Source code` は開発用のソースコードで、アプリの起動用ZIPではありません。

現在はベータ版です。ゲームのフォントや背景によって、文字の読み落としや誤訳が起きる場合があります。

## できること

- 読み取るゲームのウィンドウと、会話欄の範囲を指定
- 英語の画面テキストを読み取り、日本語へ翻訳
- ゲーム画面上部へ、クリックを妨げない形で訳を重ねて表示
- オートマチックで文章の変化を自動検知、マニュアルで指定キーによる読み取り
- 対象のゲームが前面にある間だけ読み取り
- アプリ内でOCR結果・翻訳結果・処理時間を確認

現在の対応言語は **英語 → 日本語** です。

## 必要なもの

- Windows 10 バージョン1903以降、またはWindows 11の **x64環境**
- Windowsの **英語（米国 / en-US）OCR言語機能**
- 翻訳用のインターネット接続
- 中継サーバーを使う場合は、管理者から受け取った **招待トークン**

配布版には.NETを同梱しています。**.NETの追加インストールや、ソースコードのビルドは不要です。** 英語OCRの言語機能はWindows側に導入する必要があります。すでに使えるPCでは追加作業は不要です。

## はじめて使うとき

### 1. ZIPを展開して起動する

ダウンロードしたZIPを右クリックして「すべて展開」し、展開先の `BridgEN.exe` を起動します。

DLLや設定ファイルも必要です。ZIP内から直接起動したり、EXEだけを別の場所へ移動したりせず、展開したフォルダーごと使ってください。

### 2. 翻訳の接続設定を保存する

1. 「翻訳の接続設定」を開きます。
2. 「中継サーバー（配布版）」を選びます。
3. サーバーURLが `https://bridgen-api.gspe.workers.dev` になっていることを確認します。管理者から別のURLを案内された場合は、そのURLを使います。
4. 自分用の招待トークンを入力し、「接続設定を保存」を押します。

中継サーバーは招待制です。トークンは管理者から個別に受け取ってください。この接続方法では、利用者自身のGemini APIキーは不要です。

<details>
<summary>自分のGemini APIキーで直接接続する場合</summary>

1. Windowsのユーザー環境変数 `GEMINI_API_KEY` に、自分のAPIキーを設定します。`GOOGLE_API_KEY` も利用できます。
2. 「翻訳の接続設定」で「Geminiへ直接接続」を選びます。
3. 「接続設定を保存」を押します。

直接接続には招待トークンと中継サーバーURLは不要です。翻訳リクエストは、自分のAPIキーを使ってGoogleへ送信されます。

</details>

### 3. 読む範囲を選ぶ

1. ゲームを起動し、会話欄など、読み取りたい文字を表示します。
2. BridgENの「対象ウィンドウ」でゲームを選びます。見つからない場合は「一覧を更新」を押します。
3. 「読む範囲を選択」を押すと、選んだゲームが前面に表示されます。最小化されていれば元に戻します。
4. 会話欄全体をドラッグで囲みます。複数行になる会話も収まるように選んでください。右クリックでキャンセルできます。

### 4. 操作モードを選び、開始する

「操作モード」で **オートマチック** と **マニュアル** を切り替えます。初回はオートマチックが選択されます。変更したモードと実行キーは自動保存され、次回起動時に引き継がれます。

**オートマチック**：「OCRを開始」を押してゲームを前面にすると、文章を自動で読み取ります。文章が安定したことを確認してから翻訳し、日本語訳をゲーム画面の上部へ表示します。

**マニュアル**：実行キーの欄をクリックし、使いたいキーを押して設定します。初期値は **F8** で、Ctrl・Shift・Altなどとの組み合わせにも対応します。「待機を開始」を押し、ゲームを前面にして実行キーを押すと、その時の画面を1枚読み取り、翻訳します。

- マニュアルでは、文章が表示され終わってからキーを押してください。キーを押すまで画面取得・OCR・翻訳は開始しません。
- 1回の押下で1回読み取ります。長押しでは繰り返し実行せず、OCR処理中の追加押下も予約しません。
- 翻訳の受信中にもう一度押すと、前の翻訳を取り消して新しい画面を読み取ります。同じ英文の完成済み訳があれば再利用します。
- 実行キーはゲームにも届くため、ゲーム内の操作と重ならないキーを選んでください。

マニュアルは `v0.1.0-beta.2` 以降で利用できます。

- 読み取りを止めるときは、BridgENの「停止」を押します。
- 別のアプリへ切り替えている間は読み取りと翻訳を停止します。ゲームへ戻ると、オートマチックは自動で再開し、マニュアルは次の実行キーを待ちます。
- 読み取る場所を変えるときは、「読む範囲を選択」で選び直します。
- 読み取り内容は「OCR結果」、日本語訳は「翻訳結果」で確認できます。「処理時間」を開くと各処理の時間を確認できます。

## 英語OCRが使えない場合

「Windowsの英語OCR機能が利用できません」と表示された場合は、Windowsの設定から英語（米国）の言語機能とOCRを追加してください。Windowsの表示言語を英語へ変更する必要はありません。

OCRの認識データは配布ZIPには含まれません。導入方法は [Microsoftの公式手順](https://learn.microsoft.com/en-us/windows/powertoys/text-extractor#install-an-ocr-language-pack) でも確認できます。リンク先はPowerToysの説明ですが、OCR言語機能はWindows共通のものです。BridgENのためにPowerToysをインストールする必要はありません。

<details>
<summary>PowerShellで英語OCRを導入する方法</summary>

**Windows PowerShellを管理者として起動**し、次のコマンドを順番に実行します。必要なWindows機能の取得にはインターネット接続が必要で、導入に数分かかる場合があります。

```powershell
Add-WindowsCapability -Online -Name 'Language.Basic~~~en-US~0.0.1.0'
Add-WindowsCapability -Online -Name 'Language.OCR~~~en-US~0.0.1.0'
```

完了後にBridgENを起動し直してください。コマンドの結果で再起動が必要と表示された場合は、Windowsを再起動します。

</details>

## 中継サーバーの利用上限

ベータ版の中継サーバーは、初期設定で次の上限を設けています。

- 1人あたり：**1日300回・1分20回**
- 利用者全体：**1日1,000回・1分60回**
- 日次上限のリセット：**日本時間の午前9時**

回数は翻訳APIへの送信を試みた回数です。送信後のキャンセルやAPIエラーも含みます。上限に達した場合は、時間を置いて利用してください。上限は運用状況に応じて変更される場合があります。

## データの取り扱い

- 画面画像のOCR処理はPC内で行い、**画像を翻訳APIへ送りません**。
- 中継サーバーを使う場合、認識した英文をCloudflareの中継サーバー経由でGoogleのGemini APIへ送ります。直接接続の場合はGoogleへ送ります。
- 中継サーバーは英文・画像・生の招待トークンを保存せず、利用上限を管理するカウンターを保存します。Google側のデータの取り扱いは、利用するGemini APIの条件に従います。
- 接続設定は `%LOCALAPPDATA%\BridgEN\connection.json` に保存します。招待トークンは、そのWindowsユーザーに紐付けて暗号化します。
- 操作モードと実行キーは `%LOCALAPPDATA%\BridgEN\ocr-settings.json` に保存します。
- 診断ログには処理の状態や文字数などを記録します。OCR本文・画像・APIキーは記録しません。

## 困ったとき

- **ゲームが一覧に出ない**：ゲームを起動してから「一覧を更新」を押してください。
- **文字が抜ける・誤認識する**：会話欄全体が選択範囲に収まっているか確認し、メニューや背景の文字が入りすぎない範囲へ選び直してください。フォントや背景によっては読み取りが難しい場合があります。
- **訳が表示されない**：ゲームが前面にあること、「OCR結果」に英文が出ていること、接続設定を保存していることを確認してください。翻訳待ちやAPIエラー時は、オーバーレイに英文を表示する場合があります。
- **招待トークンが無効と表示される**：管理者から受け取ったトークンを確認し、保存し直してください。解決しない場合は管理者へ連絡してください。
- **翻訳APIのエラー後に再試行したい**：OCRを一度停止してから、再開してください。

不具合を報告する場合は、[GitHub Issues](https://github.com/giasupe/BridgEN/issues) に、利用バージョン・Windowsのバージョン・ゲーム名・再現手順・表示されたエラーを記載してください。APIキーや招待トークンは載せないでください。

## アップデート

起動中のBridgENを終了し、新しいReleaseのZIPを別のフォルダーへ展開して起動してください。接続設定はWindowsのユーザーフォルダーに保存されるため、同じWindowsユーザーであれば引き継がれます。
